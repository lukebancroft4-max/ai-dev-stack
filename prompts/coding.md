# Coding prompts

## New feature
"""
Build [feature] in [language/framework]. Requirements:
- [requirement 1]
- [requirement 2]
Follow existing code style. Add tests. Explain what changed.
"""

## Debug
"""
This code throws [error]. Here's the relevant snippet:
[paste code]
[paste stack trace]
Find the root cause and propose a minimal fix.
"""

## Refactor
"""
Refactor [file/module] to improve [readability/performance/testability]
without changing behavior. Show the diff and explain tradeoffs.
"""
