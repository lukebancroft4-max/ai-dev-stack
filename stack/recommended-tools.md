# Recommended tools by job type

## AI-assisted coding (vibe coding)
- **Claude Code** — CLI agent, best for multi-file tasks
- **Cursor** — AI-first editor
- **Aider** — terminal-based pair programmer
- **GitHub Copilot** — inline completions in VS Code

## Local / private AI
- **Ollama** — run models locally (llama3.2, qwen2.5, deepseek-r1)
- **LM Studio** — GUI for local models + OpenAI-compatible API

## Web / app development
- Node.js 22 + pnpm
- Python 3.12 + venv
- Docker + Docker Compose
- Tailwind CSS, React/Next.js (via create-next-app)

## Research
- JupyterLab
- VS Code + Python/Jupyter extensions
- arXiv CLI helpers (see scripts/)

## Version control
- Git + GitHub CLI (`gh`)
